## Status
ROADMAP-PR: open PR #2444 (DiracScatteringAndNonlinearFourierTransform) specifies it: the scattering limit `a(∞,·)`, `b(∞,·)`, `ρ(∞,·) = b(∞,·)/a(∞,·)` locally uniformly on `ℂ₊` for square-integrable potentials (§5.1, Prop 43.1 on `ℂ₊`), the non-linear Fourier transform `q⌃ = ρ(∞,·)` with truncations `(q_T)⌃ = b(T,·)/a(T,·)` (§5.2, Def 43.2(b)), its boundary function on `ℝ` (§§5.2–5.3), and the convergence of truncations in `L²(ℝ)` and in `Π`-measure, with `a(T,·) → a(∞,·)`, `b(T,·) → b(∞,·)` in `Π`-measure (§5.5, Prop 43.1 on `ℝ`, Def 43.2(a)); the pointwise convergence theorem of the paper is §9.6. It rests on the scattering functions of #44 (PR #2444 Layer 4). No merged roadmap specifies it.

## Prerequisite chain
1. `L²(ℝ₊)`, convergence in measure, finite measure `Π`: in Mathlib.
2. Carathéodory linear ODE: in Tau Ceti for bounded coefficients only; `L¹_loc` with entire parameter dependence: PR #2444 Layer 1.
3. Scattering functions `a(t,z)`, `b(t,z)` and their properties (#44): PR #2444 Layers 3–4.
4. Truncated transform `b(T,·)/a(T,·)` (Def 43.2(b)): PR #2444 §5.2.
5. Bounded holomorphic functions, Fatou, outer functions on `ℂ₊`: PR #2444 Layer 2 (§2.2 on merged AutomorphicSpectralTheory §0.5).
6. Existence of scattering limits on `ℂ₊` and in `Π`-measure on ℝ (Prop 43.1): PR #2444 §5.1, §5.5.
7. Nonlinear Fourier transform `b(∞,·)/a(∞,·)` (Def 43.2(a)): PR #2444 §§5.2–5.5.
