## Status
PARTIAL-CODE. Tau Ceti has the smooth mapping class group `TauCeti.MappingClassGroup I M` = π₀ Diff(M, ∂M) of a compact manifold, possibly with boundary, with `Mod⁺` for an orientation (`Geometry/Diffeomorphism/MappingClassGroup.lean`): the object of merged GeometricTopology 1.7.2 for compact surfaces with boundary fixed pointwise. The punctured-surface group of Definition 59 (orientation-preserving homeomorphisms of `Σ_g` preserving the puncture set, punctures may be permuted, modulo isotopy) is not in code; it is a target of open PR #1231 §5.9, PR #2266 §0.2 builds the pure subgroup `PMod(g, b, p)` on it and PR #2263 §2.1 the braid group as the mapping class group of the marked disc. Borderline call: the code is a close variant (compact `M`, smooth, ∂M fixed pointwise), not the punctured-surface group; the two agree only after capping or marking, which no code provides.

## Mathlib
No mapping class groups. Has `Homeomorph` groups, `ContinuousMap.Homotopy`, compact-open topology, `Homeomorph` topological group structure on locally compact spaces, `Diffeomorph`.

## Tau Ceti code
- `TauCeti.MappingClassGroup I M` (`Geometry/Diffeomorphism/MappingClassGroup.lean`): for a compact Hausdorff smooth manifold `M`, possibly with boundary, the quotient of the relative diffeomorphism group `Diff(M, ∂M)` (`TauCeti.RelativeDiff`, weak Whitney topology) by the path component of the identity, with `mk`, `mk_surjective`, `ker_mk`, `mk_eq_mk_iff` (same class iff joined by a path), `lift`, `mk_final_eq_one` (a diffeotopy ends in the trivial class) and the subgroup `orientationPreserving o` (`Mod⁺(M)`). Diffeomorphisms, boundary fixed pointwise; no homeomorphism version, no punctures or marked points, no Dehn twists, no computation for surfaces.
- Diffeomorphism groups and isotopies exist: the relative diffeomorphism group `TauCeti.RelativeDiff` (`Geometry/Diffeomorphism/FixingSubgroup/Basic.lean`) with the topology of `Geometry/Diffeomorphism/Topology.lean`, `TauCeti.Diffeotopy` (`Geometry/Diffeomorphism/Diffeotopy/Basic.lean`), `TauCeti.SmoothIsotopic` (`Geometry/Manifold/SmoothIsotopy/Basic.lean`), `SmoothAmbientIsotopic`, `ContinuousAmbientIsotopic` (`Geometry/Manifold/SmoothEmbedding/...`), `TauCeti.Isotopic` (named in PR #1169). Surface groups as presented groups `TauCeti.SurfaceGroup.Orientable g m` (`GroupTheory/SurfaceGroup/Basic.lean`). Group-theoretic `dehnTwist` for HNN extensions/pushouts only (`GroupTheory/HNNExtension/DehnTwist.lean`, `GroupTheory/PushoutI/DehnTwist.lean`).

## Merged roadmaps

Not punctured surfaces. Mod(F) and Mod⁺(F) are in code (`TauCeti.MappingClassGroup`, in every dimension); the surface theorems and Dehn twists are not.
