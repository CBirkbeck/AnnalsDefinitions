## Status
ROADMAP-PR. Open PR #1169 (TeichmullerGeometry) §4.2 defines `OuterAut Γ = MulAut Γ ⧸ Inn(Γ)` for every group (61.1). Open PR #2430 (SurfaceGroupCharacterVarieties) §§3.1–3.3 constructs the outer action `Ψ_x : Mod^±(X) → Out(π₁(X, x))` for any path-connected space with its laws (well-definedness, homomorphism, basepoint change), restricts it to `Mod_{g,n}` and identifies it with the outer class through which PR #1231 §5.9 lets `Mod(S)` act on finite coverings (61.2–61.4); its §1.3 and §3.5 give the action of `Out(Γ)` and `Mod_{g,n}` on `Hom(Γ, H)/H`. PR #1231 §5.9 defines `Mod(S)` of a punctured surface and its action on finite coverings "through `Out(π₁ S)`", but neither `Out(Γ)` nor `Ψ` (its `Ψ` is the symplectic representation on `H₁`). PR #2266 §0.2 adds the based action of `PMod(g, b, p + 1)` on `π₁(Σ_{g,b,p}, x)`, the outer action of `PMod(g, b, p)`, and `pureMappingClassAut g n ≤ MulAut (surfaceGroup g n)` (automorphisms sending each peripheral loop to a conjugate), with the image of `PMod` contained in it. No merged roadmap specifies them for surfaces. Depends on #59.

## Mathlib
No `Out` as a named group, but `MulAut.conj : G →* MulAut G` (`Algebra/Group/End.lean`) makes `MulAut G ⧸ MulAut.conj.range` a one-liner. Basepoint change `FundamentalGroup.fundamentalGroupMulEquivOfPath`, induced maps `FundamentalGroup.mapOfEq` (`AlgebraicTopology/FundamentalGroupoid/FundamentalGroup.lean`).

## Tau Ceti code
- `TauCeti.ContinuousOut G = ContinuousAut G ⧸ conj.range` (`Topology/Algebra/Group/ContinuousAut/Basic.lean`); `outerAction : E ⧸ N →* ContinuousOut N` for group extensions (`.../ContinuousAut/OuterAction.lean`). With the discrete topology this is Out(Γ).
- Surface groups as presented groups `TauCeti.SurfaceGroup.Orientable g m` with peripheral elements (`GroupTheory/SurfaceGroup/Basic.lean`), not identified with the topological `π₁`.
- No homeomorphism-to-Out homomorphism for spaces. The only mapping class group is the smooth `TauCeti.MappingClassGroup I M` = π₀ Diff(M, ∂M) of a compact manifold (`Geometry/Diffeomorphism/MappingClassGroup.lean`), with no action on `π₁` and no punctures.
