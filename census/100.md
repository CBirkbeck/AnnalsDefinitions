## Prerequisite chain
1. Triangular lattice graph on ℤ², faces, lozenge tilings as perfect matchings of the hexagonal dual (100.1): Mathlib graph theory; PR #2422 Layer 1.
2. Tiling space as closed subset of `{0,1}^{E}`, compact metrizable, shift action of ℤ²: Mathlib (product topology); PR #2422 §4.4, §5.1.
3. Height function `H_M` (100.2): PR #2422 §2.5.
4. Gibbs (uniform DLR) property (100.3.1): PR #2422 §4.5 (specifications as Mathlib kernels), §5.4 (`IsLozengeGibbs` in cylinder form).
5. Translation invariance and ergodicity under ℤ² (100.3.2): Mathlib `ErgodicVAdd`/`ErgodicSMul`; extreme-point equivalence for countable-group actions in Tau Ceti (`ErgodicSMul.iff_mem_extremePoints`).
6. Slope (100.3.3): PR #2422 §6.1. Existence in Theorem 100.4 and the determinantal kernel (Kenyon–Okounkov–Sheffield, Okounkov–Reshetikhin): PR #2422 §§9.5–9.7. Sheffield's uniqueness (100.4, needed for 100.5's "the"): unplanned (PR #2422's named Part II).
